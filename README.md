# FUELIFY

Fuel. Earn. Repeat.

Premium petrol pump management + customer loyalty platform.

## Stack
Next.js + TypeScript + Tailwind + Framer Motion + Supabase + Vercel.

## Experiences
- Customer: wallet, receipt scanning, verification, points, rewards, redemption, vehicles.
- Owner: station operations, sales, inventory, tanks, pumps, employees, shifts, loyalty, reports, audit.
- Employee: shift, sales, receipt verification, customer lookup and redemption.

## Security
Supabase Auth + PostgreSQL RLS + server-side validation. Never expose service-role credentials to the browser.

## Development
Copy .env.example to .env.local, install dependencies, then run npm run dev.
